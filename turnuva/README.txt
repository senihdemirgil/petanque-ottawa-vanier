PÉTANQUE OTTAWA-VANIER — PWA V4

This package is an installable Progressive Web App (PWA).

NEW PWA FEATURES
- Install on Android / Chrome / Edge like an app.
- iPhone / iPad Add to Home Screen support.
- POV logo used as the app icon.
- Standalone full-screen app window.
- Offline tournament-manager shell after the site has been loaded once.
- Network-first updates so new GitHub deployments do not get stuck on an old app.js version.
- Same Swiss system, 13–7 BYE rule, 4/8/16/32 Championship bracket, and optional equal-size Consolation bracket.
- Live QR scoreboard still requires internet because spectators connect to the organizer live.

IMPORTANT
Do not upload only index.html. The manifest, service worker and icons are what make it installable.

INSTALL
Android/Chrome/Edge: open the site and press Install App when it appears.
iPhone/iPad: open the site in Safari > Share > Add to Home Screen.
Windows/Mac Chrome/Edge: use Install App in the address bar or the site button when available.
